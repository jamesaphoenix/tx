Write the design, save your coding agent's plan, then work through linked tasks.
tx keeps document files beside the code and task state in a local SQLite database.

## The workflow

1. [Write the design](/docs/primitives/docs). Describe the approach and the rules the code must preserve.
2. [Save the plan](/docs/primitives/plans). Copy the implementation plan your coding agent already produced.
3. [Create tasks](/docs/primitives/tasks). Give each task an observable acceptance criterion and attach it to the plan.
4. [Verify the invariants](/docs/primitives/invariants). Map enforcement code and meaningful tests, then record execution evidence.

Tasks also work on their own for small changes. Add a PRD or overview when the work
needs a separate requirements contract or system map.

## Start here

[Getting started](/docs/getting-started) takes you from installation to a linked task.
[Interfaces](/docs/interfaces) covers the dashboard, CLI, REST, MCP and TypeScript SDK.

implementation.
