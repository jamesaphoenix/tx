description: Labels
---

Use `tx task label add <name>`, `tx task label assign <task-id> <label>` and `tx task label list`.
Filter work with `tx task ready --label <label>`. Labels are ordinary task metadata.
Use `tx task label --help` for update, unassign and delete.

```bash
tx task label --help
```
