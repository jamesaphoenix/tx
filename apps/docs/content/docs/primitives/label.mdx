## Purpose

Use labels for filtering and grouping tasks. Labels do not trigger agents or
execution rules.

## Commands

```bash
tx task label add "Feature"
tx task label list
tx task label assign <task-id> "Feature"
tx task show <task-id>
tx task label unassign <task-id> "Feature"
```

Run `tx task label --help` for colours and deletion.

## Workflow

Choose a small set of labels that help find work. Apply them in the CLI or dashboard.
Use [task](./tasks) dependencies for blockers and plan attachments for specification
traceability. Labels are also available through the MCP task label tools.
