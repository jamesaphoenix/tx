`tx init --codex` or `tx init --claude` installs `tx-tasks`, `tx-docs`,
`tx-plan` and `verify-invariants`. These cover authoring tasks, specs and agent
plan copies, and mapping invariants to code and executed test evidence.
Run `tx skills sync` to update tx-owned files while keeping unrelated guides.

```bash
tx skills sync
```
