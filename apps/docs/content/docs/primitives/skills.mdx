## Purpose

Ship only task creation, doc authoring, agent-plan copying and invariant verification
instructions. No agents or execution loops are included.

## Commands

```bash
tx init --claude
tx init --codex
tx skills sync
```

Run `tx skills --help` for generation and sync options. Sync preserves unrelated skills.

## Workflow

- `tx-tasks`: create tasks, hierarchy and dependencies.
- `tx-docs`: author and connect PRDs/design docs.
- `tx-plan`: copy a normal coding-agent plan into docs and link its source.
- `verify-invariants`: map rules into code/tests and verify real execution evidence.

Keep planning and execution in your coding agent. tx maintains the
**spec -> plan -> tasks** graph and verification records.
