Use `tx sync export`, `tx sync import`, `tx sync hydrate` and `tx sync status`.
Streams under `.tx/streams` are git-friendly append-only data. Import rejects malformed
or unknown events, validates recognised retired events and reports them as ignored.
Hydrate replays retained projections without truncating existing tables.
Old tables and stream files remain available for backup and a later downgrade.
Run `tx sync --help` for supported options.

```bash
tx sync status
```
