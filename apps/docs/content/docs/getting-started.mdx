---
title: Getting started
description: Create a task and connect specifications, plans and tests
---

Install `@jamesaphoenix/tx-cli`, run `tx init` and create a task with `tx task add`.
Use the [task guide](/docs/primitives/tasks) and [plan guide](/docs/primitives/plans).
Run `tx init --codex` or `tx init --claude` to install four short authoring guides.
The [migration guide](/docs/migration) covers v0.20 changes.
